# ADR-006 隐私架构：服务器可解密的自托管同步（非端到端加密）

状态：已接受 · 2026-10-16

背景：服务端要解析账单、运行 CP-SAT、合并同步，就必须读到明文；任务书禁止在此前提下宣称"服务器永远无法解密"。
决策：业务数据在服务端以明文（磁盘级加密由部署决定）存储；原始附件用信封加密（KEK 在 secret 文件、DEK 每工作空间）；日志/崩溃报告/通知/埋点不含业务内容；后台 RBAC 禁止 operator 看账单正文；隐私说明如实写明"服务器运营者可读取数据"。备份用用户口令派生密钥加密。AI 只收最小化脱敏字段且逐次授权。
备选：端到端加密 + 纯客户端计算（放弃于 v1：需放弃服务端求解/解析；保留为未来模式）；混合（按文档逐次授权解密：对附件采用，对结构化数据不采用）。
后果：用户须信任自己的 VPS；提供"导出并删除"的完整路径。
