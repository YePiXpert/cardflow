# ADR-010 通知：本地通知为核心，服务端推送可选

状态：已接受 · 2026-10-16

决策：v1 核心 = flutter_local_notifications 调度 + 应用内消息中心；服务端通知（APNs/FCM）为可选外部依赖（需 Apple 推送密钥/FCM 项目），缺失时服务端只在同步时下发"待调度提醒"由客户端本地排程。去重键 = `kind:entity_id:due_date`。
后果：不承诺必达；权限状态在首页可见。
补充（2026-10-16）：iOS 由用户自签（ADR-015），用免费 Apple ID 签名时没有 APNs 推送能力；本地通知路线不受影响。
