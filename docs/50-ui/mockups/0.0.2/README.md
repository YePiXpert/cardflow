# 公测版 0.0.2 界面重做 · 设计稿

来源：用户 2026-10-19 对 0.0.1 的反馈——"界面太丑，没有使用欲望"；并拿正在用的信用卡小程序对比："虽然不好看，但是能看出多少钱和日期"。

0.0.1 的问题（主会话在 iPhone 尺寸下渲染演示空间核对）：
- 卡包页每张卡只显示"可用容量"，看不到账单金额、待还金额、出账日、还款日。
- 总览页最显眼的位置是"演示/纯本地"标签、"待核对的还款""差异"按钮和"负债四分法"的解释文字；真正要看的"欠多少、哪天还"埋在下面。
- 主题把所有容器层级映射成同一种表面色，所有强调色映射成同一个蓝色，层次很平；每行堆 3~4 个状态标签。

设计方向：**打开就能看到每张卡欠多少、哪天出账、哪天还款**，其余信息往详情页收。

| 文件 | 内容 |
|---|---|
| `home-dark.png` / `home-light.png` | 新首页"卡账"：本期待还合计与 3 天内到期、总额度与可用；"今天刷哪张"（免息天数最长的卡）；每张卡一行——待还（大字）、账单金额、N 天后出账、N 天后还款，按还款日排序，已还清的排后面 |
| `card-dark.png` | 卡片详情：卡面（银行色）、额度条、本期进度（出账日 → 今天 → 还款日，"还剩 N 天"）、待还与最低还款、本期账单与未出账、三个主要操作、账单历史 |
| `cash-dark.png` | 现金：7/30/90/180 天切换、余额曲线（0 线、储备虚线、缺口标红）、"接下来"的收支与还款列表 |
| `overview.png` | 四张并排 |
| `mock.html`、`render_mock.py` | 设计稿源文件（HTML），用 Playwright + Chromium 渲染成 3 倍图 |

说明：设计稿里的银行、卡号末四位与金额都是虚构的演示数据；字体是 Linux 上的文泉驿微米黑，真机用系统字体（苹方）。银行标识用"银行简称首字 + 品牌色色块"，不使用银行的商标图形。
