## 1. 本地库 v5
- `currentSchemaVersion` → 5；4→5 只 expand；冻结 SQL；新建与从 v1–v4 升级结构一致（sqlite_master 逐项相同）；迁移与 `user_version` 同事务；旧版 App 打开报 `schema_too_new`。
- `loans`：id、workspace_id、lender_name（贷款机构，G2/G5 文本规则）、product_name、principal_minor（> 0）、currency（13 种之一，默认 CNY）、annual_rate（十进制文本，0 < r ≤ 1）、repayment_method（CHECK 只允许 `interest_only_bullet`，以后再放宽）、interest_basis（`monthly_fixed` / `daily_360` / `daily_365`）、start_on、maturity_on（> start_on）、payment_day（1–31，小月取月末）、first_payment_on（可空：默认放款日之后第一个还款日；与放款日同日号时为一个月后）、cash_account_id（可空，复合外键指向同空间的现金账户）、status（`active` / `settled` / `cancelled`）、note、created_at、updated_at、deleted_at。
- `loan_payments`（还款计划）：id、workspace_id、loan_id、period_no、due_on、interest_minor（按计息方式算出的值）、principal_minor（最后一期 = 本金，其余 0）、amount_override_minor（可空：按贷款机构账单更正的本期应还总额）、override_reason、status（`scheduled` / `paid` / `cancelled`）、paid_on、paid_amount_minor、created_at、updated_at。`(loan_id, period_no)` 在未作废的行中唯一。
- 贷款生成的现金事件必须能认出来（P-08 不能直接改或删，要回到贷款页处理），且不能破坏"新建 vs 升级结构一致"：可以在 `loan_payments` 上存 `cash_event_id`（复合外键），也可以另建关联表；**不要**用 `ALTER TABLE cash_events ADD COLUMN`（新建库与升级库的建表文本会不同）。做法写进 README。
- 新表进 `workspaceDataTables`；没有 `id` 的表登记 `_rowKeys`；演示数据给每张新表至少一行（例如"星海银行 · 星闪贷"，本金 100,000，年化 3.6%，按月固定，按月付息到期还本，扣款账户工资卡）。

## 2. 计算（纯函数 + 单测，`lib/data/loans/loan_schedule.dart` 一类位置）
- 还款日：从 first_payment_on 起每月 payment_day（小月取月末，2 月 29 日只在闰年），直到到期日；到期日不在还款日上时，最后一期是到期日。
- 利息（`HALF_UP` 到最小单位）：`monthly_fixed` 每个整月 = 本金 × 年化 ÷ 12；首期或末期不足一个月时按日计算（本金 × 年化 ÷ 360 × 实际天数），并在计划里标"不足一月，按日计"；`daily_360` / `daily_365` 每期 = 本金 × 年化 × 实际天数 ÷ 360 / 365，实际天数 = 上一还款日（首期为放款日）到本期还款日。
- 每期应还 = 更正值（有则用）否则利息 + 本金部分。汇总：已付利息、剩余利息、总利息、剩余本金。
- 修改贷款（利率、还款日、到期日、计息方式、扣款账户）：已付的期不动；未付的期按新条件重算，原来未付期上的更正值作废前要确认；对应的计划现金事件同步改或作废。删除贷款 = 软删除，未付期作废、计划现金事件作废，已付期留作历史。提前还款与结清在后续版本，界面写"后续版本提供"。

## 3. 与现金和首页的衔接
- 有扣款账户时，每个未付期在扣款账户上生成一条计划现金事件（类别"其他债务"、负数、日期 = 还款日、标签"{机构简称}{产品名} 利息"/"还本付息"）；"标记本期已还"（实付日期 ≤ 今天、实付金额默认本期应还）把它变为确定、已发生，日期与金额改为实付。没有扣款账户时贷款照常显示，资金日历不计入，并在贷款页写明"未选扣款账户，资金日历未计入"。
- 资金日历窗口外的未付期进入尾部责任（`TailObligation`，`source: 'loan'`）。
- 卡账首页（U-1 的读模型上扩展）："贷款"分组在信用卡列表之后，每笔贷款一行：机构徽标（与银行徽标同一套颜色）、"{机构简称} · {产品名}"、右侧"按月付息 · 年化 x%"；本期应还（大字，下一笔未付期的应还）、本金（小字）；"N 天后还款 · MM-DD · 利息/还本付息"（今天 → 注意色"今天还款"；过期未标记 → 危险色"已逾期 N 天"）；"N 天后还本 · 日期"。按下一次还款日排序。汇总卡另起一行"另有贷款 N 笔 · 最近 MM-DD ¥x"（与信用卡待还分开，不相加）；"3 天内到期"计入贷款的期。
- 贷款详情（`loan-dark.png`）：头部（机构、产品、本金、年化与计息方式、放款到到期的进度条、"还有 N 天到期"）；下次还款（日期、几天后、金额、计算式，例如"利息 = 100,000 × 3.6% ÷ 12"）；已付利息与剩余利息；"标记本期已还""改本期金额"（理由可选）；还款计划列表（未付在前，已付折叠为"已还 N 期 ›"，最后一期加粗"还本付息"）；"修改""删除"。
- 新增/修改表单：机构（可从内置银行名单选，也可手填）、产品名、本金、年化利率（%）、计息方式、放款日、到期日、每月还款日、首次还款日（可选）、扣款账户；下面实时预览：前 3 期、最后一期、总利息。校验：本金 > 0；0 < 年化 ≤ 100%，超过 24% 时提示"请核对年化利率"但可保存；到期日晚于放款日；每月还款日 1–31；G1–G5 文本规则。
- 入口：卡账页"＋"菜单的"添加贷款"、"贷款"分组标题右侧的"＋ 添加"、"我的"里的"全部贷款"。

## 4. 测试
- 计算：PRD R-CASH-11 的验收例（100,000 × 3.6% 按月固定 → 每期 300.00、末期 100,300.00）；按日 360/365 跨 2 月、闰年（2028-02-29）、月末还款日（31 日在 30 天月份）；首期不足一月；到期日不在还款日；四舍五入边界；总利息 = 各期之和。
- 仓库：新增、修改后重算（已付不动）、更正金额、标记已还、删除；生成/确认/作废计划现金事件；P-08 不能直接改贷款生成的事件；隔离测试覆盖新表；v4 → v5 迁移与新建一致、回滚与重跑。
- 组件：首页贷款行、详情、表单预览与校验、标记已还；可访问性 2/3 倍字号；禁用文案与编号检查覆盖新页面；截图工具（U-1 的 `test/tool/screenshots_test.dart`）加贷款详情与表单。
