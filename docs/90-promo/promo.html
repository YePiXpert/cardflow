账单、分期、还款

  • 正式账单的每个版本都保留原值；人工修正必须写理由
  • 分期成本并列显示：名义年化 vs 按现金流 IRR 算的实际年化——不把月费率 ×12 叫"实际"

  • 同日同额两笔 → 疑似重复，负债只核销一次；退款待核对；贷方余额单列

可复现 · 可解释 · 可审计

不是推荐卡片的营销工具，也不是支付工具：是一本你自己能查账的本子

纯本地

数据只在你的 iPhone；没有账号、没有服务器、不联网也能用

加密存储

SQLite3 Multiple Ciphers · ChaCha20；密钥放在系统钥匙串，打不开就停，不降级

不碰卡号

只记末四位；任何完整卡号都拒绝保存；不采集任何数据

结论可解释

假设、数据问题、确认层级全部显示；没有"安全"二字，也没有绿勾

规格先行

38 组验收样例（F-01～F-38）；Dart 领域包与 Python 引擎逐字节一致

公开构建

代码在 GitHub；CI 自动出未签名 IPA，自己签名安装
