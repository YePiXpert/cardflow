卡序 0.0.2 公测版：打开卡账即可查看每张卡的待还金额、出账日和还款日。本版包含 U-1 界面重做与 F-1 账单、还款修复；iOS 纯本地使用。

## 本版变化

- 四个标签：卡账、现金、规划、我的；原有页面与旧路径仍可进入。
- 卡账汇总、按日期/金额排序、今天刷哪张；卡片详情增加快捷「记本期账单」「还清本期」，还款按登记、银行入账、银行确认推进。
- 现金页增加余额曲线、时间窗口、未计入的信用卡应还提示与表格入口。
- 「我的」增加可记忆的隐藏金额开关与重置本地数据入口；深浅色、放大字号与弹层布局已检查。
- 修正账单接续、已出账消费转分期、还款入账与冲正后的有效状态；已还清账单也可人工修正并重新计算剩余应还。

## 安装与公测说明

附件为 **未签名 IPA**。使用安装 0.0.1 时的同一签名身份和 Bundle ID `li.yep.cardflow`，连同 App、Flutter、objective_c、sqlite3mc 四个嵌套 framework 一起重签，然后直接覆盖安装。不要先删除旧 App。最低 iOS 15.0；版本 0.0.2，构建号 82。

数据只保存在这台 iPhone 上，加密存储，卡序不会上传到任何服务器。删除 App 或「重置本地数据」会删除全部数据；目前没有 App 自身的备份与导出，换手机不能直接打开旧加密库。安装不需要向项目提供签名证书。

## 手机验收

1. 覆盖安装后确认原有卡片、账单与现金数据保留；「我的 → 诊断信息」确认版本 0.0.2、构建 82、Bundle ID 与加密状态正常。
2. 在真实空间对照银行账单核对首页待还、出账日、还款日与卡片详情；切换四个标签，打开原有账单、还款、资金日历入口。
3. 在演示空间选择尚未录账单的卡（如「北辰 ···· 3001」），试「记本期账单」：核对默认日期，填写测试金额并保存，检查首页与详情一致；已有同日账单时查看或修正原账单，不重复录入。演示日期固定为 2026-10-16。
4. 对刚录入的演示账单使用「还清本期」；核对金额及扣款账户，依次检查「已登记 → 银行已入账 → 银行确认」及剩余应还。真实数据中仅在取得对应银行证据后推进状态；这些按钮只登记记录，不执行银行转账。
5. 在现金页切换窗口和口径、打开表格及「未计入」；在「我的」开隐藏金额并重启，确认保持隐藏。切换系统深浅色及放大字体，检查金额、日期和弹层可读。检查重置入口及取消即可，不必执行删除。
6. 退出演示确认真实数据不变；回传诊断信息及卡住的操作步骤。自动测试与构建通过不代替这轮真机业务验收。

## 已知限制

- 信用卡应还在登记还款前不自动计入资金日历，界面会显示「未计入」。还款入账后额度仍需手动更新快照。
- 快捷还清本期需要可用于还款的现金账户；快捷「银行已入账」把扣款与入账时点记为现在，历史时点请用还款详情的完整流程。
- 登记还款须先有本期账单；既有分期在部分旧账单场景下仍采用偏大的保守负债口径（BL-36）。
- 演示数据日期固定；消费规划、活动与权益仍为后续版本功能。本版没有消费贷、导入或同步。
