卡序 0.0.3：消费前比较刷哪张卡。

- 用卡页输入金额、币种、消费日期；在额度足够的卡里优先选择预计还款日更晚者，显示推荐原因、其他可用卡和未参与原因。
- 三个入口：用卡、卡片、我的。移除记账、还款、现金、日历、情景与未实现的活动入口；不要求录入现金或账单。
- 沿用本机加密数据库与卡片额度、账期设置；比较不记账，也不预占额度。工作空间切换清空输入与结果。

限制：假设还款资金充足，仅做单笔单卡比较；不换汇、不比较返现积分。额度需手工更新，预计账期以银行实际入账为准；“距预计还款 N 天”不承诺实际免息资格。

安装：这是未签名 IPA。用自己的既有工具重签主程序和全部嵌套 framework，保留 Bundle ID `li.yep.cardflow` 后安装。项目和 CI 不接触用户证书。

手机验收：
1. 添加两张卡，设置额度和账期；不录入现金、账单或还款。
2. 输入金额和日期，检查推荐卡与预计还款日；改变金额和日期重算。
3. 超出额度、缺规则时检查原因；其他资料完整的卡仍应可推荐。
4. 在演示空间比较后退出，确认输入和结果清空；测试隐藏金额、深浅色及放大字体。
5. 我的 → 诊断信息，回传版本/构建与具体失败步骤。
