## 手机验收（待用户操作）

1. 用自己的签名流程处理 IPA 主程序及嵌套 framework，保留 Bundle ID `li.yep.cardflow`，安装打开。
2. 手工添加两张卡，分别填写可用额度、账单日和还款规则；不录入现金、账单或还款。
3. 用卡页输入消费金额和日期，核对推荐卡、可用额度、预计账单/还款日及原因；换一个日期和金额重新比较。
4. 输入超过所有卡额度的金额，检查不足原因；缺规则的卡应提示补资料，其他完整卡仍可推荐。
5. 演示空间比较后退出，确认输入和结果已清空；检查隐藏金额、深浅色、放大字体和三个导航入口。
6. 我的 → 诊断信息，回传版本/构建及具体卡住的步骤。

## 当前限制

只有单卡单币种比较；不换汇、不比较活动返现或积分、不验证实际免息资格。额度来自手工快照，超过 7 天提示更新；预计日期以银行实际入账和还款为准。真机业务尚未验收。发布与自动验证的最终结果见下方。
